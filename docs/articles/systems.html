Differential expression, and what it misses

TCGA liver cancer: 15,312 genes, 5,671 differential, and the isoform shifts hiding behind them

  • Article

  • Where the two disagree

Ten patients from the TCGA liver hepatocellular carcinoma cohort, each contributing a tumour sample and an adjacent normal one. Twenty libraries, ~60,000 genes measured by RNA sequencing, and one question: which genes change between the two tissues.

The naive answer is thousands of them. The interesting part is what that answer leaves out.

Before any testing, the counts get a variance-stabilising transform and a PCA. The first two components should separate the conditions if the design is sound, and they do — normal samples tight on one side at 18% of variance, tumours spread across the other.

That spread is the problem. Two of the ten patients are female, and the vertical structure in the tumour cluster is partly gender. A model of condition alone is then not testing condition; it is testing condition plus whatever gender happens to correlate with.

Refitting with ~ gender + condition costs 107 genes: 5,778 significant before, 5,671 after at a 5% false discovery rate. The estimate is that it matters less than the shape of the PCA suggests, which is itself a result — a confound that is present but not dominant is different from one that isn’t there.

The 5,671 genes get ranked by their test statistic and pushed through preranked GSEA against the MSigDB biological-process collection, 15 to 500 genes per set. 865 gene sets come back significant.

They are overwhelmingly cell cycle: chromosome segregation, nuclear chromosome segregation, mitotic nuclear division, sister chromatid segregation, DNA replication, with normalised enrichment scores around 2.3 to 2.85 and adjusted p-values below 10⁻³⁴. The direction is what liver cancer biology predicts — a tumour that has lost differentiation and re-entered the cell cycle.

Against that, the top negative enrichment scores are metabolic: organic acid catabolism, small-molecule catabolism, fatty acid metabolism, at −2.6 to −3.0. Those are the processes the normal liver does and the tumour stops doing.

Two coherent stories, pointing opposite ways, from one ranked list. A leading-edge gene from the top set is NUF2, part of the NDC80 kinetochore complex that attaches chromosomes to spindle microtubules; UBE2C and NEK2 are in the same short list, both mitotic.

DESeq2 tests genes. A gene can be equally abundant in both tissues and still be doing something different — making a different isoform of the same transcript. That is differential transcript usage, and it is invisible to a gene-level test by construction.

DEXSeq asks the other question. Counts per isoform, a generalised linear model with a per-sample baseline and a per-isoform baseline, then a likelihood-ratio test of whether the condition interacts with isoform identity:

Over 519 genes, 880 isoforms show significant usage shifts. The top five by adjusted p-value are KHK, UGP2, CLEC1B, FN1 and GSTZ1 — fructose metabolism, glycogen precursor synthesis, a platelet receptor, an extracellular matrix protein, and an oxidative-stress enzyme. Liver-specific metabolism, immune recognition and tissue architecture, which is the same story as the gene-level analysis told from a different angle.

Collapsing isoform results to one row per gene, then re-adjusting the false discovery rate across that new family, gives 15,312 genes tested by both methods. 1,947 are significant for isoform usage, 4,594 for overall expression, and 843 in both.

Fisher’s exact test on the 2×2 table gives an odds ratio of about 2 and p = 1.1 × 10⁻⁴⁰. Genes with differential usage are twice as likely as chance to also be differentially expressed — a real association, and nowhere near a complete one. Each method finds signals the other does not.

That gap is the point. Running the same GSEA on both gene rankings and plotting the normalised enrichment scores against each other shows the answer at pathway level:

Spearman correlation of NES −0.082
significant in both a minority
pathways significant only in one the majority

A negative correlation between the two rankings means that for a great many pathways, the gene-level analysis and the isoform-level analysis do not merely disagree on magnitude — they disagree on direction. Not on the same pathways, but not in the same direction.

The conservative reading is that isoform-level testing is noisier and this is what noise looks like. The reading I would defend is narrower: at the gene level, 5,671 genes separate tumour from normal, and that number is an upper bound on how much of the biology the analysis captured. The rest is in how the transcripts are put together.

bg_terms

# Step 2: Filter the virtual pulldown to remove "sticky" hub proteins
# Function takes a subgraph, the full parent graph, and a cutoff threshold.
filter_virtual_pulldown <- function(subGraph, parentGraph, cutoff) {
  
  # --- Check that both graphs have vertex names (proteins identified by name) ---
  if (is.null(V(subGraph)$name) || is.null(V(parentGraph)$name))
    stop("Both graphs must have vertex 'name' attributes.")
  
  # --- Mode: "all" ensures degrees are calculated without direction ---
  mode <- "all"
  
  # --- Extract node names from the subgraph ---
  vn <- V(subGraph)$name
  
  # --- Degree in the full graph: total number of connections each node has globally ---
  deg_full <- degree(parentGraph, v = vn, mode = mode)
  
  # --- Degree in the subgraph: number of connections each node has inside the pulldown ---
  deg_internal <- degree(subGraph, mode = mode)
  
  # --- Combine results into a data frame for each node ---
  res <- data.frame(
    node          = vn,
    deg_internal  = deg_internal,
    deg_full      = deg_full,
    # Fraction of a node’s total connections that lie within this pulldown
    frac_internal = ifelse(deg_full > 0, deg_internal / deg_full, NA_real_),
    stringsAsFactors = FALSE
  )
  
  # --- Keep only nodes that meet the cutoff for internal fraction ---
  nodes_to_keep <- res$node[!is.na(res$frac_internal) & res$frac_internal >= cutoff]
  
  # --- Build a new subgraph using only the kept nodes ---
  filteredSubGraph <- induced_subgraph(subGraph, vids = V(subGraph)[name %in% nodes_to_keep])
  
  # --- Add the fraction value as a vertex attribute (for later inspection) ---
  V(filteredSubGraph)$frac_internal <- res$frac_internal[match(V(filteredSubGraph)$name, res$node)]
  
  # --- Return the filtered network ---
  filteredSubGraph
}

# GOAL:
# Collapse isoform-level DEXSeq results to one row per gene by:
#   (a) picking the most significant isoform per gene (smallest RAW p-value),
#   (b) then recomputing FDR across genes (new hypothesis family).
# WHY:
#   The original DEXSeq 'padj' adjusts across ALL isoforms/features. After collapsing to
#   one p-value per gene, that 'padj' is no longer valid; we must re-adjust at the gene level.

dexseqResultGene <-
  dexseqResult %>%
  as.data.frame() %>%        # Convert S4 results object to a plain data.frame
  as_tibble() %>%            # and then to a tibble for friendly dplyr usage

  # 1) Keep only tested features (rows where the test statistic exists).
  #    NAs often arise from zero counts, filtering, or non-convergence.
  filter(!is.na(stat)) %>%

  # 2) Select and rename columns we need downstream.
  #    - groupID   : gene identifier as supplied when building the DEXSeqDataSet (here: Ensembl gene id)
  #    - featureID : feature identifier (here: transcript/isoform id, because we set featureID = transcript_id)
  #    - stat      : test statistic for the DEU test on this feature
  #    - log2fold_Primary_Tumor_Solid_Tissue_Normal : feature-level log2FC for the 'condition' contrast
  #    - pvalue    : RAW p-value for this feature (used to pick per-gene "best" isoform)
  #    - padj      : feature-level FDR across ALL features (not valid after collapsing to genes)
  dplyr::select(
    gene_id    = groupID,
    isoform_id = featureID,
    stat,
    log2FC     = log2fold_Primary_Tumor_Solid_Tissue_Normal,
    pvalue,
    padj
  ) %>%

  # 3) Group by gene to operate within each gene's set of isoforms/features.
  group_by(gene_id) %>%

  # 4) Within each gene, keep the single isoform with the smallest RAW p-value.
  #    WHY raw p (not feature-level padj)? Because we are about to define a NEW testing family
  #    (one p per gene) and must feed those raw p-values into a fresh multiple-testing correction.
  slice_min(
    order_by = pvalue,
    n = 1,
    with_ties = FALSE  # if two isoforms tie exactly, pick one arbitrarily (see tie-breaking alternative below)
  ) %>%

  # 5) Ungroup so the next mutate acts on the entire tibble.
  ungroup() %>%

  # 6) Recompute FDR across genes (new hypothesis family = "one p per gene").
  #    This is statistically correct and typically more powerful (fewer tests than "all isoforms").
  #    Note: method = "fdr" is an alias for Benjamini–Hochberg ("BH").
  mutate(padj = p.adjust(pvalue, method = "fdr"))

# Do exactly the same thing for the DESeq2 gene-level results.
# Again, add a TRUE/FALSE flag for significance.

deseq_gene <- deseq2Results %>%
  mutate(
    gene_id = strip_ver(gene_id),   # remove version suffix
    deseq_padj = padj,              # keep padj column
    deseq_sig  = !is.na(padj) & padj < alpha  # mark significant genes
  ) %>%
  dplyr::select(gene_id, deseq_padj, deseq_sig)
deseq_gene

###############################################
# STEP 5 — Define the universe of comparable genes
###############################################

# Both DEXSeq and DESeq2 may have tested slightly different sets of genes.
# We only want to compare the ones that appear in BOTH.
# This gives us the "gene universe" for the overlap test.
univ <- intersect(dex_gene$gene_id, deseq_gene$gene_id)

# Sanity check: how many genes are shared between the two analyses?
length(univ)

###############################################
# STEP 6 — Combine both results side-by-side
###############################################

# Merge the two tables by gene_id, so that each gene now has:
# - its DEXSeq significance (dex_sig)
# - its DESeq2 significance (deseq_sig)

both <- dex_gene %>%
  filter(gene_id %in% univ) %>%      # keep only shared genes
  inner_join(deseq_gene, by = "gene_id")  # join DESeq2 results by gene_id

# Quick look to make sure it worked
head(both)

###############################################
# STEP 7 — Count overlaps (the "both TRUE" genes)
###############################################

# This is the number of genes significant in both methods.
n_overlap <- sum(both$dex_sig & both$deseq_sig)

# Also useful to know total counts for context.
n_dex_sig   <- sum(both$dex_sig)
n_deseq_sig <- sum(both$deseq_sig)
n_universe  <- nrow(both)

# Print them
cat("Universe:", n_universe, "\n")
cat("DEXSeq significant:", n_dex_sig, "\n")
cat("DESeq2 significant:", n_deseq_sig, "\n")
cat("Overlap:", n_overlap, "\n")


###############################################
# STEP 8 — Build the 2×2 contingency table
###############################################

# This table shows every possible combination:
# - Neither method found it
# - Only DESeq2 found it
# - Only DEXSeq found it
# - Both found it

contig_tab <- table(DEXSeq = both$dex_sig, DESeq2 = both$deseq_sig)
contig_tab

###############################################
# STEP 9 — Run Fisher’s exact test (ORA)
###############################################

# Fisher’s Exact Test asks:
# "Is the overlap (TRUE + TRUE) larger than we would expect by random chance?"

ft <- fisher.test(contig_tab, alternative = "greater")

# Print the result
ft

  dex_sig      = n_dex_sig,
  deseq_sig    = n_deseq_sig,
  overlap      = n_overlap,

# GOAL
# Compare pathway-level enrichment between DESeq2 (gene-level)
# and DEXSeq (isoform-usage) by plotting their NES scores
# against each other. Color points by which analysis called
# the pathway significant (DEXSeq only, DESeq2 only, Both, None).
#
# INPUTS WE ALREADY HAVE:
#   fg_deseq : fgseaMultilevel() result for DESeq2 stats
#   fg_dex   : fgseaMultilevel() result for DEXSeq  stats
#   alpha    : significance cutoff (e.g., 0.05)
#
# OUTPUT:
#   1) A merged data.frame `cmp` with NES + padj from both analyses
#   2) A scatterplot NES(DESeq2) vs NES(DEXSeq) colored by significance class
############################################################

library(dplyr)
library(ggplot2)

# 1) Keep just the columns we need from each fgsea result and rename them
#    so they won't collide when we join the two tables later.
#    - pathway : the gene set name (join key)
#    - NES     : normalized enrichment score (effect size; up/down and magnitude)
#    - padj    : FDR-adjusted p-value for the gene set (significance)
#
#    `transmute()` creates a new data.frame with only the columns we list.
#    We also rename NES/padj to method-specific names (NES_de/padj_de, NES_dx/padj_dx).
de_df <- fg_deseq %>%
  transmute(
    pathway,
    NES_de  = NES,
    padj_de = padj
  )

dx_df <- fg_dex %>%
  transmute(
    pathway,
    NES_dx  = NES,
    padj_dx = padj
  )

# 2) Merge (inner join) on 'pathway' so we keep only gene sets present in BOTH
#    results. This is necessary because we want to plot NES_de vs NES_dx for
#    the same pathway on each row.
#
#    After the join, add a "sig_cat" (significance category) column:
#      - "Both"         : padj < alpha in DESeq2 AND in DEXSeq
#      - "DESeq2 only"  : padj < alpha in DESeq2, but not in DEXSeq
#      - "DEXSeq only"  : padj < alpha in DEXSeq, but not in DESeq2
#      - "None"         : padj >= alpha in both
#
#    Finally, we make sig_cat an ordered factor so the legend uses a sensible order.
cmp <- inner_join(de_df, dx_df, by = "pathway") %>%
  # fgsea can leave a few rows with NA NES/padj (e.g., "unbalanced" sets).
  # Drop NAs so plotting/statistics don't choke.
  filter(!is.na(NES_de), !is.na(NES_dx), !is.na(padj_de), !is.na(padj_dx)) %>%
  mutate(
    sig_cat = case_when(
      padj_de < alpha & padj_dx < alpha ~ "Both",
      padj_de < alpha & padj_dx >= alpha ~ "DESeq2 only",
      padj_de >= alpha & padj_dx < alpha ~ "DEXSeq only",
      TRUE ~ "None"
    ),
    sig_cat = factor(sig_cat, levels = c("Both", "DESeq2 only", "DEXSeq only", "None"))
  )

# 3) (Optional but useful) Compute correlations so we can report a number.
#    Spearman = monotonic rank correlation (robust to outliers, scale-free).
#    Pearson  = linear correlation.
spearman_cor <- cor(cmp$NES_de, cmp$NES_dx, method = "spearman", use = "complete.obs")
pearson_cor  <- cor(cmp$NES_de, cmp$NES_dx, method = "pearson",  use = "complete.obs")

# 4) Make the scatterplot:
#    - x = DESeq2 NES; y = DEXSeq NES
#    - color by significance category
#    - add a linear trend line (geom_smooth with method = "lm") WITHOUT a gray CI ribbon
#      to avoid clutter; the line just indicates the direction/strength visually.
p <- ggplot(cmp, aes(x = NES_de, y = NES_dx, color = sig_cat)) +
  geom_point(alpha = 0.8) +                 # points for each pathway
  geom_smooth(method = "lm", se = FALSE) +  # dashed trend line (no CI)
  labs(
    x = "NES (DESeq2 fgsea)",               # clear axis labels
    y = "NES (DEXSeq fgsea)",
    color = "Significance",
    title = "NES comparison: DESeq2 vs DEXSeq (fgseaMultilevel)",
    subtitle = paste0("Spearman r = ", round(spearman_cor, 3),
                      " | Pearson r = ", round(pearson_cor, 3),
                      " | alpha = ", alpha)
  ) +
  theme_minimal()

# 5) Print the plot
p
